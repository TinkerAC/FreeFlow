# 歌单位置排序功能实现

## 概述

本次更新为项目添加了歌单和曲目的位置排序功能，允许用户通过拖放操作自定义歌单顺序，以及在歌单详情页面按多种方式对曲目进行排序。

## 主要功能

### 1. 数据库变更

- **playlists 表**: 新增 `position` 字段（INTEGER），用于记录歌单在前端中的显示位置
- **playlist_detail 表**: 新增 `position` 字段（INTEGER），用于记录曲目在歌单中的显示位置
- 初始值按入库时间降序排列

### 2. 前端功能

#### 2.1 MusicLibrary 组件（歌单库）
- ✅ 支持拖放操作调整歌单顺序
- ✅ 实时更新歌单位置到数据库
- ✅ 拖拽时提供视觉反馈（透明度、鼠标样式）

#### 2.2 PlaylistView 组件（歌单详情）
- ✅ 新增排序选择器，支持以下排序方式：
  - 默认排序（按 position 字段）
  - 按标题排序
  - 按艺术家排序
  - 按添加日期升序
  - 按添加日期降序

### 3. API 变更

#### 新增 IPC 通道
```typescript
Channels.Playlist.UpdatePositions: 'playlist:update-positions'
Channels.Playlist.UpdateTrackPositions: 'playlist:update-track-positions'
```

#### 新增 API 方法
```typescript
// 前端 API
playlistContext.updatePlaylistPositions(updates: Array<{playlist_id: number, position: number}>)
playlistContext.updateTrackPositions(playlistId: number, updates: Array<{track_id: number, position: number}>)

// 后端服务
PlaylistService.updatePlaylistPositions(updates)
PlaylistService.updateTrackPositions(playlistId, updates)
```

## 使用说明

### 1. 调整歌单顺序

在音乐库侧边栏（展开状态）：
1. 长按歌单项
2. 拖动到目标位置
3. 松开鼠标
4. 新顺序自动保存到数据库

### 2. 排序歌单中的曲目

在歌单详情页面：
1. 点击顶部操作栏中的排序选择器
2. 选择排序方式
3. 曲目列表立即重新排序
4. "默认排序" 会保存当前顺序到数据库

## 注意事项

1. **数据库迁移**: 首次运行前必须执行迁移 SQL
2. **兼容性**: 旧数据的 position 值会自动初始化为按 created_at 降序
3. **性能**: 批量更新使用 Promise.all 并行执行
4. **用户体验**: 拖放操作提供实时视觉反馈

## 相关问题排查

### 歌单顺序没有保存
- 检查数据库 position 字段是否存在
- 查看浏览器控制台是否有错误
- 确认 IPC 通信是否正常

### 拖放不生效
- 检查 LibraryItem 的 draggable 属性
- 验证事件处理函数是否正确绑定
- 查看 CSS 是否影响了拖放行为

### 排序结果不正确
- 确认 applySortAndFilter 逻辑
- 检查数据源的 ORDER BY 子句
- 验证 TrackEntity 的字段值
