基于关键点检测的增强现实交互系统设计实现

摘要：手势作为人类通用的一种肢体语言，在日常的交流中起着重要的作用，如何

进行手势识别是当前人机交互领域的研究热点。基于手部关键点检测的增强现实交互系

统是一种将手部姿态检测技术与增强现实技术相结合的交互系统。该系统可以实现通过

手部姿态控制虚拟物体的运动、调整虚拟物体的位置，为用户提供更加直观、自然的交

互体验。该系统由手部检测、手部关键点检测、手部追踪、手势识别、操作逻辑及应用

五部分组成。本文将从这五部分以及系统的需求分析、开发技术分析来阐述该系统的设

计与实现。

关键词：手部检测；关键点检测；手势识别；增强现实

The Design and Implementation of Hand Key Point Detection-based

Augmented Reality Interaction System

Abstract:  Gestures,  as  a  universal  form  of  body  language,  play  a  significant  role  in

everyday communication for humans. The study of gesture recognition is currently a hot topic

in  the  field  of  human-computer  interaction.  The  hand  gesture-based  augmented  reality

interaction system is  an interactive system  that combines hand posture detection technology

with augmented reality technology. This system can achieve operations such as controlling the

movement and position of virtual objects through hand gestures, providing users with a more

intuitive and natural interaction experience. The system consists of five parts: hand detection,

hand key point detection, hand tracking, gesture recognition, operation logic, and application.

This article will elaborate on the design and implementation of the system based on these five

sections,  as  well  as  the  requirements  analysis  and  development  technology  analysis  of  the

system.

Key words: Hand detection; key point detection; gesture recognition; augmented reality.

1.1    研究背景及发展趋势

传统的增强现实交互方式往往需要用户通过鼠标、键盘等外部设备进行操作，而手

部关键点检测技术可以更加自然地捕捉用户的手部动作，提高用户的交互体验，提供了

一种非接触式控制的方法[1]。未来的生活场景朝着越来越智能化的方向发展，智能家居、

的语言工具。美国的手语识别系统可以将手势翻译为语音，对广大残疾朋友有莫大帮助。

2012 年，国内彩电康佳公司的 X8100 系列是国内首款运用手势来识别电视的，通过上

面的摄像头来识别人类的手势，手势的水平方向运动可以用于调台和翻页，轻拍动作可

以选择和确定，手部运动控制指示着鼠标的移动[3]。

究方向之一[4]。随着深度学习的快速发展，基于深度学习的手部检测和行为分析方法取

得了显著的进展。卷积神经网络在特征学习方面的优越性不断提高，这也使得手部检测

和行为分析的准确性得到了明显提升。基于手部关键点检测的增强现实交互系统正是计

算机视觉和增强现实技术相结合的产物。

在计算机视觉领域，研究者们提出了多种有效的手部检测、手部关键点检测和手部

姿态识别算法。其中包括基于卷积神经网络（CNN）和深度神经网络（DNN）的方法等。

这些算法通过对手部图像进行分析和学习，能够准确地检测手部位置、关键点位置以及

手势姿态。而在增强现实领域，研究者们也提出了多种有效的增强现实技术，如基于标

记的增强现实技术和基于视觉里程计（VIO）的增强现实技术等。

3.1    YOLOv5

YOLOv5 是一种高效的目标检测算法，采用了单阶段检测器的架构，能够在图像中

高效地检测出多个目标，并同时提供它们的位置和类别信息。相比其前身 YOLOv4，

YOLOv5 在检测性能方面取得了显著的改进，同时具备更快的速度。这使得 YOLOv5 成

为一种广受欢迎的目标检测网络，具有高精度的检测结果、快速的检测速度和易于移植

的特点[6]。

YOLOv5 的主要改进包括引入了一种新的骨干网络架构——CSPDarkNet，该网络结

构在计算效率和检测性能之间取得了良好的平衡。此外，YOLOv5 还采用了更高效的检

测头设计，提供了更精确的锚框生成方式，并优化了训练策略和数据增强方法等。这些

改进使得 YOLOv5 在目标检测任务中能够取得更好的性能。

由于 YOLOv5 具备高效、准确和易于实现等优点，它在目标检测领域得到了广泛的

应用。许多研究者和开发者选择使用 YOLOv5 作为他们的目标检测算法，因为它能够在

不同的应用场景中取得优异的表现。此外，YOLOv5 在多个基准测试中展现出领先的性

能，成为目标检测领域的一项重要技术。

总的来说，YOLOv5 的引入对于目标检测领域具有重要的意义。它不仅提供了高效

且准确的目标检测能力，而且在实际应用中具备较快的速度和易于实现的特点，为各种

视觉任务和应用提供了可靠的解决方案。随着技术的不断发展，YOLOv5 有望继续演进

并推动目标检测领域的进一步发展。

3.2    ResNet50

ResNet50（Residual Network-50）是一种深度卷积神经网络模型，属于 ResNet 系列

网络的重要成员，由微软研究院的 Kaiming He 等人于 2015 年提出。该模型主要用于图

像分类任务，并在 ImageNet 数据集上取得了较高的准确率。

ResNet50 的主要特点是引入了残差块（residual block），以缓解深度网络训练过程中

的梯度消失和梯度爆炸问题。通过在输入和输出之间引入跨层连接（shortcut connection），

残差块可以更有效地传递信息，提高网络的训练效率和准确率。此外，ResNet50 还采用

4.3.3    关键代码

本文系统中计算两帧画面的 bounding box 的 IoU 值的函数的代码如下：

def __compute_iou(self, x1, y1, x2, y2):

        box1 = np.array([x1, y1, x2, y2])

        iou_list = []

        for box2 in self.last_box:

                h = max(0, min(box1[2], box2[2]) - max(box1[0], box2[0]))

                w = max(0, min(box1[3], box2[3]) - max(box1[1], box2[1]))

                area_box1 = ((box1[2] - box1[0]) * (box1[3] - box1[1]))

                area_box2 = ((box2[2] - box2[0]) * (box2[3] - box2[1]))

                inter = w * h

                union = area_box1 + area_box2 - inter

                iou = inter / union

                iou_list.append(iou)

        iou_list = np.array(iou_list)

        return iou_list

其中输入的“x1”、“y1”、“x2”、“y2”分别为第一个 bounding box 的左上角的 x 轴、

y 轴坐标和第二个 bounding box 的左上角的 x 轴、y 轴坐标。

4.4.1    手势识别方法的演变

早期的手势识别研究是基于数据手套等可穿戴设备实现，利用可穿戴设备的传感器

捕捉手势及关节点的位置和角度信息进而实现手势识别。常用的方法有数据手套[16]和手

部标签标记[17]，数字手套是一种常用的手势识别设备，它通过在手部戴上传感器来捕捉

手部运动的数据，再通过算法进行分析和处理，以达到识别手势的目的。然而，数字手

套也存在一些弊端：数字手套需要在手部穿戴传感器，而传感器的数量通常较多，因此

数字手套可能会比较笨重，不太适合长时间佩戴；数字手套的制造成本较高，因为它需

要大量的传感器和处理器等硬件设备，并且需要进行复杂的信号处理和算法开发。

到了深度学习时代，深度卷积神经网络（CNN）的出现。深度学习技术的发展使得

手势识别的准确率大幅提高。CNN 是一种特殊的神经网络，可以通过学习图像特征来自

动提取手势的特征，从而实现高效的手势识别。例如，Zhai 等人在 2021 年对基于深度

学习的高效手部检测和手势识别方法研究中，提出了一种基于轻量级网络 SqueezeNet 的
手部检测和手势识别模型 SF-FCNet[18]。

计算两向量的夹角 cos 值的函数如下所示：

def vectors_to_angle(p1, p2, p3, p4):

        x1 = p1[0] - p2[0]

        y1 = p1[1] - p2[1]

        x2 = p3[0] - p4[0]

        y2 = p3[1] - p4[1]

        a = x1 * x2 + y1 * y2

        b = ((x1 ** 2 + y1 ** 2) ** 0.5) * ((x2 ** 2 + y2 ** 2) ** 0.5)

        angle = a / b

        return angle

5    结论与展望

本增强现实交互系统基于手部关键点检测模块，对各个功能模块进行了详细的开发。

本系统采用 Python 编写，在 PyCharm  Community 平台开发，本系统所使用的计算机搭

载 MX250 显卡，系统采用 NVIDIA CUDA 来使用 GPU 加速计算，摄像头使用了 1080P

高清摄像头。在手部检测功能方面，本文系统使用 YOLOv5 目标检测算法。在关键点检

测方面，本文系统采用基于深度学习的手部关键点检测的模型。对于手部追踪方面，本

文系统基于 IoU 的计算进行手部轨迹的追踪。对于手势识别方面，本文系统采用了基于

手部骨架的手势识别，充分利用了手部关键点信息。交互逻辑方面，系统中不同手势可

以被识别为不同的操作，例如“点击”、“长按”等。利用这些交互逻辑，本文系统开发

了图像内容识别、虚拟键盘、虚拟钢琴等应用。

本文系统还存在一些问题。第一，本文的手势识别采用了基于手部骨架的手势识别，

利用检测出的关键点得到手部姿态的信息，包括特定关键点组成的向量之间的角度，以

此进行手势的识别。虽然该方法所需要的图片数量很少，但是所适用的手势的特点是各

个关节角度差异明显，且角度变化范围较小，使用该方法进行手势识别的精度依赖于关

键点检测的精度，对于一些复杂的手势或者与现有手势特征较为相近的手势，识别准确

率较低。改进方法可以是使用深度学习的方法来进行手势识别。第二，本文系统的优化

还需要改进，由于设备性能的限制，在我的设备上处理一帧图片的时间需要一百毫秒左

右，也就是实时画面每秒仅有大约 10 帧，改进方法可以是优化系统的代码或者使用性

能更好的设备。
