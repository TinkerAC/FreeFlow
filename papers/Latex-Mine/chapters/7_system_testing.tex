\section{智能合约测试}

合约测试主要验证PlatformHub、MusicAccess1155和RoyaltySplitter的核心逻辑。当前项目已覆盖以下测试点：

\begin{enumerate}
  \item 付费作品发布后，用户支付正确金额可获得访问凭证。
  \item 公开作品发布后，用户默认拥有访问权限。
  \item ERC-1155访问凭证不可在用户之间转让。
  \item 只有创作者可以修改作品销售配置。
\end{enumerate}

后续正式论文应补充合约测试命令、测试截图和Sepolia烟雾测试结果。

\section{性能测试与结果分析}

性能测试建议从检索响应时间、播放启动时间和发布流程耗时三个方面展开。

\begin{enumerate}
  \item 检索响应时间：分别在50、100、300和500条候选数据下测试平均响应时间和P95响应时间。
  \item 播放启动时间：比较缓存命中和缓存未命中时，从点击播放到开始播放的耗时。
  \item 发布流程耗时：统计音频上传、metadata上传和链上交易确认的耗时。
\end{enumerate}

后续正式论文应补充折线图或柱状图展示测试结果。
