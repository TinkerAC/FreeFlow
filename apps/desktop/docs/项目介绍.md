# 项目介绍 - FreeFlow

## 1. 项目概述

FreeFlow 是一款基于 Electron 和 React 技术栈构建的现代化桌面音乐播放器。本项目旨在为用户提供一个高度自由、可聚合多个音乐平台内容的统一播放体验。其界面设计精美,复刻了 Spotify 的用户界面,注重用户体验与视觉效果。

与传统的单平台音乐客户端不同,FreeFlow 的核心设计理念是“聚合”与“开放”。通过模块化的内容提供商 (Content Provider) 架构,它能够接入并播放来自不同来源的音乐,解决了用户因版权问题需要在多个应用间频繁切换的痛点。

本项目不仅是一个功能完善的音乐播放器,更是一个涵盖了前端、后端、桌面端应用开发、软件架构设计等多个领域的综合性软件工程实践。

## 2. 核心功能

- **多平台音乐聚合**: 内置多个音乐内容提供商,支持播放和搜索来自不同平台的音乐资源。
- **现代化播放器体验**:
    - 仿 Spotify 的精美用户界面,支持浅色/深色主题。
    - 支持播放控制、播放队列、音量调节、播放进度控制等基础功能。
    - 歌词动态展示功能。
- **播放列表与歌单管理**:
    - 支持创建、编辑和删除个人歌单。
    - 可收藏歌曲到“我喜欢的音乐”。
- **本地缓存与离线播放**:
    - 对播放过的音频文件进行本地缓存,减少网络请求,实现离线播放。
    - 提供音频文件下载功能。
- **跨平台支持**: 基于 Electron 框架,可打包为 Windows, macOS, Linux 等主流桌面操作系统应用。
- **系统集成**: 支持系统托盘图标、快捷键等原生桌面应用特性。

## 3. 技术栈

本项目采用了业界主流的前后端分离思想,在 Electron 的主进程和渲染进程中分别承担不同职责。

### 3.1. 核心框架
- **Electron**: 用于构建跨平台桌面应用的核心框架。
- **Node.js**: 作为 Electron 主进程的运行环境,负责所有后端逻辑。

### 3.2. 渲染进程 (Frontend)
- **React**: 用于构建用户界面的核心视图库。
- **TypeScript**: 为项目提供强大的类型系统,提升代码健壮性。
- **React Router**: 管理应用内的路由和页面导航。
- **Tailwind CSS & Material-UI**: 提供高效、美观的 UI 组件和样式解决方案。
- **Framer Motion**: 用于实现流畅、自然的动画效果,提升用户体验。
- **Axios**: 用于在渲染进程和主进程或外部服务间进行 HTTP 通信。

### 3.3. 主进程 (Backend)
- **TypeScript & Node.js**: 主进程的开发语言和环境。
- **Sequelize & SQLite**: 使用 Sequelize ORM 配合 SQLite 数据库,进行歌单、播放历史等本地数据的持久化管理。
- **Express.js**: 在主进程中搭建本地服务器,用于处理音频代理、API 请求等。
- **InversifyJS**: 一个强大的控制反转 (IoC) 容器,用于管理类之间的依赖关系,实现了高度解耦的模块化架构。
- **Cheerio & JSDOM**: 在部分内容提供商中,用于解析和抓取网页数据。

### 3.4. 构建与工程化
- **Webpack**: 用于项目代码的打包、编译和优化。
- **ESLint & Prettier**: 保证代码风格统一和质量。
- **Jest**: 用于进行单元测试,确保代码逻辑的正确性。
